# LGD India Administrative Hierarchy API

A keyless REST API serving India's official administrative hierarchy (States → Districts → Sub-Districts) with government-assigned LGD codes, sourced from the Ministry of Panchayati Raj's Local Government Directory. PIN-code lookup is intentionally out of scope — already well-served by `api.postalpincode.in` and others (see `DOCS/RESEARCH.md`).

Status: pre-design
